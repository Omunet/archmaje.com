# archmaje-site

An October 21, 2026 snapshot of the publicly visible content of https://archmaje.com — the site of Maud Espinasse / DJ MAJE — kept as source material for a future rebuild.

- `pages/` — visible text of each page in reading order (3 pages)
- `assets/images/` — images, logos and favicon from wp-content/uploads (195 files, original filenames)
- `site-map.md` — menu structure and page list
- `style-notes.md` — colours, fonts, theme (Virtue) and plugins (Elementor, etc.)

This does **not** include the WordPress files, theme/plugin code, or the database. Captured read-only; nothing on the live site was changed and no forms were submitted. Files over 25 MB would be listed here: none found.

## Static site (GitHub Pages)

`index.html`, `art-creation/index.html`, `mua/index.html`, `404.html` and `assets/css/style.css` are a plain HTML/CSS rebuild (no PHP, no JS). Layout and image order come from the Wayback Machine capture; text is the original. The extract notes now live in `_source/` (plain Markdown, harmless if served). `TAB2-scaled.jpg` and `TAB3-scaled.jpg` were never captured and are omitted from the "characters" gallery.
